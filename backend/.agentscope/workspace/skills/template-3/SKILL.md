# 排版模板：会议纪要模板

## 风格标签
于总版本

## 模板结构
本模板包含以下标准章节，改写时请确保完整输出：

1. **## 会议信息** — 日期、时间、地点、召集人、与会人
2. **## 会议讨论** — 按议题或发言人组织内容，使用 **X总意见：** 格式
3. **## 会议决策** — 明确列出决策事项和责任部门

## 使用说明
改写完成后，可主动询问用户是否需要导出文件。
若用户同意，调用 export_docx 工具（参数：content=改写内容），生成 .md 文件。
